# Atlas 混合檢索 RAG 架構

## 技術架構
本專案是 Java / Spring Boot 後端、Vue 3 / TypeScript 前端的文件知識庫助理。後端使用 REST API，打包部署時，前端與 API 由同一個 Java 服務提供；開發時前端透過同源 /api 代理存取後端。

## 文件攝取
文件先保留 Markdown 標題與段落，再以 BGE-M3 embedding 比較相鄰段落，合併同一標題內相近的概念。文件具有部門、擁有者、允許角色、到期日、標籤與版本 metadata。權限由伺服器認證帳號決定，過期內容在搜尋之前就排除。

## 混合搜尋與重排
BM25 處理關鍵字與精準技術名詞，BGE-M3 產生 1024 維多語向量並存進自架 Qdrant。兩路候選以 RRF 合併，再由 BGE reranker v2 m3 重新排序，選取最多五個來源段落。詞彙涵蓋率與重排 logit 都不是回答信心分數。

## 模型回答
Qwen3 4B Instruct 2507 本地開源模型依據來源生成繁體中文回答。模型使用 llama.cpp 在 CPU 執行，回覆須包含引用；後端驗證引用指向目前可讀的文件與版本。沒有證據時拒答。來源正確不保證生成句子都正確，仍需檢查語意忠實度與答案相關性。

## 執行與費用
打包前端與後端共用 loopback port 18081；開發 preview 仍可使用 4175。Qdrant 16333，LLM 18111，embedding 18112，reranker 18113。使用本地開源模型，沒有付費模型 API 呼叫；執行環境本身的成本不由模型 API 計費。
